# Product Requirements Document

## Product
AI-Powered B2B Document Intelligence Assistant

## Problem
B2B users frequently need to locate information across product catalogues, supplier terms, delivery policies and other business documents.

## Target Users
Procurement professionals, B2B buyers, operations teams and sales teams.

## User Story
As a B2B buyer, I want to ask questions about uploaded business documents so that I can quickly retrieve relevant information without manually searching every document.

## MVP
1. Multi-PDF upload
2. Page-aware extraction
3. Metadata-aware chunking
4. Vector retrieval
5. Grounded LLM answers
6. Source/page display
7. Unsupported-query handling
8. Response-time tracking

## Success Metrics
- Retrieval accuracy
- Grounded answer rate
- Unsupported-answer rate
- Average response latency
- User feedback

## Risks
- Poor PDF extraction
- Incorrect retrieval
- LLM hallucination
- API latency/cost
- Tables/images not being parsed correctly

## Future Scope
Reranking, query routing, supplier comparison, requirement extraction and automated enquiry generation.
